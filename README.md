# Bài tập kiểm tra 2 - Quản lý sinh viên bằng LINQ to XML

## 1. Giới thiệu
Chương trình viết bằng ngôn ngữ C# (.NET Core / .NET 8) sử dụng thư viện **LINQ to XML** (`System.Xml.Linq`) để quản lý và thực hiện các truy vấn dữ liệu từ tệp `students.xml`.

## 2. Cấu trúc dự án
- `Program.cs`: Mã nguồn chính của chương trình console tích hợp menu tương tác từ chức năng 1 đến 15.
- `students.xml`: Tệp dữ liệu XML lưu trữ thông tin sinh viên.
- `README.md`: Hướng dẫn vận hành chương trình.

## 3. Cách chạy chương trình
1. Đảm bảo máy tính đã cài đặt **.NET 8 SDK** (hoặc .NET Framework tương thích).
2. Đặt file `students.xml` vào cùng thư mục chứa file chạy `.exe` của dự án (hoặc thư mục gốc của project).
3. Mở Terminal / Visual Studio, build và chạy ứng dụng (`dotnet run` hoặc nhấn `F5` trong Visual Studio).
4. Sử dụng bàn phím để nhập số tương ứng với các chức năng trong menu hiển thị trên màn hình.# Kiemtralan2
